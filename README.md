# Data Science Browser - Branch Oumaima

Approche structurelle basée sur les graphes de citations pour la recherche d'information scientifique.

## 🎯 Approche

**Graphe de Citations**: Exploitation de la structure du réseau de citations pour améliorer la recherche.

## 📊 Méthodes

- Analyse de la structure du graphe de citations
- Mesures de centralité (PageRank, betweenness, etc.)
- Représentations augmentées combinant texte et structure

## 🚀 Quick Start

```bash
git clone https://github.com/thomas0barand/data-science-browser.git
cd data-science-browser
git checkout oumaima
poetry install
```

## 📁 Contenu

- Notebook d'exploration
- Scripts d'analyse de graphe
- Résultats et visualisations
